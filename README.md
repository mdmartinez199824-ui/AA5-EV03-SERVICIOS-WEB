# CitaSalud – Servicios web

Evidencia **GA7-220501096-AA5-EV03** – Diseño y desarrollo de servicios web del proyecto formativo.

Aprendiz: **Michel Dayana Martínez Fajardo**

El proyecto implementa una API REST en Java con Spring Boot para registro e inicio de sesión de usuarios y gestión de citas médicas. Incluye operaciones para crear, listar, consultar, actualizar y eliminar citas.

## Ejecutar
Requisitos: Java 17 y Maven.

```bash
mvn spring-boot:run
```

La aplicación inicia en `http://localhost:8080`.

La documentación detallada se encuentra en `documentacion/SERVICIOS_WEB.md`.
